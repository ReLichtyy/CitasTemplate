# AGENTS.md

Fuente única de instrucciones para este repo: **CLAUDE.md** (en este mismo directorio).

Antes de cualquier tarea en este repositorio, lee y aplica **`./CLAUDE.md`** íntegramente. Su contenido prevalece sobre cualquier guía general.

Cuando trabajes dentro de un workspace, carga también su propio `CLAUDE.md`:

- `apiBase/CLAUDE.md` — invariantes del backend (NestJS).
- `Template/CLAUDE.md` — invariantes del frontend (React + Vite).

Esas reglas se dan por sabidas y no se repiten en los specs de cada módulo o vista.
